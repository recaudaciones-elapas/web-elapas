# Web ELAPAS

Interfaz web del MVP del proyecto **Sistema de Gestión de Recaudaciones y Cortes para ELAPAS - Sucre**.

## Objetivo
Permitir la consulta y visualización básica de clientes, lecturas, cortes y deuda desde una interfaz web.

## Alcance inicial
- Inicio de sesión básico
- Dashboard principal
- Lista de clientes
- Lista de lecturas
- Lista de cortes
- Consulta de deuda

## Estado actual
Repositorio creado para la fase inicial del proyecto.

## Integración
Este módulo consumirá los servicios expuestos por `api-elapas` o `elapas-api`, según el nombre que definan para el backend.
